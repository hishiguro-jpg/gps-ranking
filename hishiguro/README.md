# hishiguro/ 社内ツール置き場

このフォルダ配下に、業務用ツールをツールごとにサブフォルダで追加していきます。
（リポジトリ直下の `app.py` 等は既存の「GPS計測 順位表ジェネレーター」で、本番稼働中のため現状のまま維持しています）

## 運用ルール

- 新しいツールを作るときは、必ず `hishiguro/<ツール名>/` にサブフォルダを作成してから着手する
- 各ツールフォルダには以下を置く
  - `README.md`：目的・使い方・依頼の背景や経緯
  - `CHANGELOG.md`：いつ・何を・なぜ変更したか（簡単な箇条書きでOK）
- 作業内容はそのつどコミット・プッシュする（未コミットの変更はセッション終了とともに失われるため）
